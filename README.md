#  Análise de Acidentes em Rodovias Federais

[![Python 3.8+](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Análise completa de acidentes em rodovias federais brasileiras (2025-2026) com dados sintéticos realistas, KPIs de impacto social e exportação para Looker Studio.

##  Funcionalidades

- Geração de dados sintéticos realistas (Poisson + fatores sazonais)
- Feature engineering com classificação de risco
- 9 visualizações exploratórias automatizadas
- KPIs de impacto social (custo estimado: R$ 350k/morte)
- Insights acionáveis com priorização
- Exportação pronta para Looker Studio
